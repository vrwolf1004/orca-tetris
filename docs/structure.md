# 구조

## 파일

```text
orca-plugin.json    매니페스트 (sandboxed-ui, 패널 tetris)
panel/index.html    패널 화면 (모니터, 게임 화면, 도움말 팝업)
panel/style.css     패널 스타일 (색은 panel.ts 의 THEMES 가 CSS 변수로 넣는다)
src/game.ts         테트리스 규칙과 상태 (입출력 없음)
src/ladder.ts       사다리게임 규칙 (입출력 없음)
src/snake.ts        스네이크 규칙 (입출력 없음)
src/minesweeper.ts  지뢰찾기 규칙 (입출력 없음)
src/i18n.ts         패널 문구 7개 언어와 t() 함수
src/panel.ts        입력, 타이머, 그리기, 화면 전환, 도움말, 언어 전환
tests/game.test.ts  테트리스 규칙 단위 테스트 (4개)
tests/games.test.ts 사다리, 스네이크, 지뢰찾기 규칙 단위 테스트 (6개)
tests/i18n.test.ts  번역 문구 치환과 키 확인 (2개)
docs/               규칙, 구조, 개발, 상태, 할 일, 소개글 준비 문서
docs/store/         스토어 이미지 (아이콘, 대표 이미지, 스크린샷, 게임별 가로 캡처)
```

## 실행 방식

- 실행 프로필은 `sandboxed-ui`입니다. 외부 프로세스, 네트워크, 파일 접근이 없습니다.
- 규칙은 `src/*.ts` 의 게임 파일에 있고, 화면과 입력은 `src/panel.ts`에 있습니다. 규칙을 바꿀 때는 게임 파일과 `tests/`만 고치면 됩니다.
- `panel/index.html`이 `<script type="module" src="../src/panel.ts">`로 TypeScript 파일을 직접 불러옵니다. 별도 빌드는 없습니다.

## 화면 구성

- 게임 화면 영역은 높이 476px로 고정합니다. 조작 버튼은 모든 게임에서 같은 위치에 있습니다.
- 게임 상자 폭은 380px입니다.
  - 테트리스: 보드 280×398, 왼쪽 패널 64px (다음 블록, 줄, 레벨, 조작 안내)
  - 사다리: 캔버스 354×422, 패널 없음, 점수는 보드 안
  - 스네이크: 캔버스 354×420, 패널 없음, 점수와 길이는 칸 위 띠
  - 지뢰찾기: 캔버스 280×420, 오른쪽 패널 64px (지뢰 수, 시간, 조작 안내)
- 상단 우측 점수(HUD)는 스네이크에서 숨기고, 테트리스와 사다리는 보드 안에 점수를 둔다.

## 역할 나눔

- **규칙(game.ts 등)**: 입출력이 없어서 테스트로 바로 검증합니다. 난수는 생성자에 함수로 넘깁니다.
- **문구(i18n.ts)**: 키마다 7개 언어 값을 둡니다. 타입으로 묶여 있어서 한 언어라도 빠지면 컴파일 에러가 납니다.
- **패널(panel.ts)**: 키 입력을 규칙 함수에 연결하고, 틱 간격마다 `tick()`을 호출한 뒤 화면을 그립니다. `THEMES` 에 게임별 팔레트가 있습니다.
- **화면(index.html, style.css)**: 테트리스 보드 캔버스, 다음 블록 캔버스, 사다리/스네이크/지뢰찾기 캔버스, 모니터, 도움말 팝업, 오버레이로 구성합니다. `data-i18n` 속성이 붙은 문구는 `applyLocale()`이 바꿉니다.

## 입력

- 키는 `window`의 `keydown`으로 받습니다. 패널을 클릭하면 포커스가 생깁니다.
- 키 역할: 1~4 게임 전환, F1 모니터, F2 언어, Ctrl+H 도움말, R 다시 시작, P 일시정지(테트리스)
- 화살표와 Space 는 기본 동작(스크롤)을 막습니다.
