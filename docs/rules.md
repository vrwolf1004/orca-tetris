# 게임 규칙

herdr-tetris 와 같은 규칙입니다. 코드 위치는 `src/game.ts` 입니다.

## 보드와 블록

- 보드: 가로 10칸, 세로 20칸.
- 블록 7종: I, O, T, S, Z, J, L.
- 새 블록은 맨 위 가운데(3열)에서 시작합니다.
- 블록은 7-bag으로 나옵니다. 7종을 한 번씩 섞어 뽑고, 다 나오면 다시 섞습니다.
- 다음 블록은 옆 패널에 미리 보입니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우로 한 칸 이동 |
| ↑ | 시계 방향 회전 |
| ↓ | 한 칸 내리기 (+1점) |
| Space | 바로 떨어뜨리기 (내려간 칸마다 +2점) |
| P | 일시정지 / 계속 |
| R | 다시 시작 |
| 1~4 | 게임 전환 (1 테트리스, 2 사다리, 3 스네이크, 4 지뢰찾기) |
| F1 | 모니터 화면과 게임 화면 전환 |
| F2 | 언어 바꾸기 |
| Ctrl+H | 도움말 열기와 닫기 |

## 회전과 벽 킥

- 회전은 시계 방향 90°입니다.
- 회전한 블록이 막히면 좌우로 0, -1, +1, -2, +2칸 밀어서 다시 시도합니다. 공식 SRS 표가 아니라 단순한 벽 킥입니다.
- 세로 방향 킥은 없습니다.

## 이동과 중력

- 틱마다 한 칸씩 내려갑니다. 틱 간격은 `max(0.05, 1.0 - 0.07 × (레벨 - 1))`초입니다.
- 더 내려갈 수 없으면 바로 고정됩니다. 고정 지연(lock delay)은 없습니다.

## 줄 제거와 점수

- 가득 찬 줄은 모두 지우고, 위의 줄을 아래로 내립니다.
- 점수표(레벨을 곱함):

| 한 번에 지운 줄 | 기본 점수 |
| --- | --- |
| 1줄 | 100 |
| 2줄 | 300 |
| 3줄 | 500 |
| 4줄 | 800 |

- 보너스는 이번 줄 제거로 줄 수가 늘기 **전** 레벨로 계산합니다.
- 레벨 = `줄 수 ÷ 10`(내림) + 1. 10줄마다 레벨이 1 오릅니다.

## 게임 오버

- 고정과 줄 제거 후 다음 블록을 맨 위에 놓을 자리가 기존 블록과 겹치면 게임 오버입니다.
- 게임 오버 후에는 조작이 무시됩니다. R 로 다시 시작합니다.

## 다른 게임

- **사다리**: 10열, 10줄 가로선 행. 시작 열을 고르면 아래 끝 열까지 가는 경로가 노랗게 표시됩니다. 끝이 없어서 게임 오버가 없습니다.
- **스네이크**: 20×30 칸 격자. 먹이를 먹으면 10점, 길이가 늘고 간격이 0.01초씩 줄어듭니다(최소 0.10초). 바로 뒤로 도는 방향은 무시합니다. 벽이나 자기 몸에 닿으면 끝납니다.
- **지뢰찾기**: 14×21 칸, 지뢰 40개. 첫 칸은 지뢰가 아니고 주변 8칸에도 지뢰가 없습니다. 지뢰를 열면 끝나고, 지뢰가 아닌 칸을 모두 열면 이깁니다. 깃발은 열리지 않은 칸에만 꽂습니다.
