# 현재 상태

## 구현됨

- 게임 4종: 테트리스, 사다리, 스네이크, 지뢰찾기. 숫자 키 1~4 로 고른다. 진행 중인 판은 다른 게임으로 갔다 와도 그대로 남는다.
- 모니터 화면(가짜 대시보드, 서비스 막대와 로그). 처음 열면 모니터가 보이고 F1 로 게임과 오간다.
- 도움말 팝업: Ctrl+H 로 열고 Esc 또는 Ctrl+H 로 닫는다. 게임마다 조작법이 다르다.
- 언어 7종(한국어, 영어, 일본어, 독일어, 스페인어, 프랑스어, 러시아어). 브라우저 언어로 정하고 F2 로 바꾼다. 모니터 화면은 영어로 고정.
- 테트리스: 7-bag, 회전과 벽 킥, 하드 드롭, 레벨, 점수(보드 안 표시), 일시정지(P), 다시 시작(R), 게임 오버 오버레이
- 스네이크: 뱀 모양 몸과 눈, 점수와 길이와 최고 기록은 칸 위 띠에 표시, 벽이나 몸에 닿으면 게임 오버 오버레이
- 지뢰찾기: 14×21칸, 지뢰 40개, 첫 칸은 항상 안전, 깃발, 시간은 오른쪽 패널에 표시, 끝나면 오버레이
- 사다리: 10열, 시작 열을 고르면 경로가 노랗게 표시, 점수 칸은 보드 안에 표시
- 게임마다 레트로 팔레트(테트리스 NES 풍, 사다리 호박색 CRT, 스네이크 게임보이, 지뢰찾기 윈도 95 풍)
- 오락실 스타일 버튼(다시 시작, 일시정지)
- 규칙 단위 테스트 10개 (`tests/game.test.ts` 4개, `tests/games.test.ts` 6개)

## 확인한 것

- 규칙 테스트 10개 통과 (`node --test tests/game.test.ts tests/games.test.ts`)
- TypeScript strict 타입체크 통과 (`src/panel.ts`)
- 매니페스트 검증 통과 (`orca plugin validate .`)
- 가짜 DOM(Node)으로 패널을 실행해 키 입력 흐름을 확인: 게임 전환, 사다리 열 이동, 스네이크와 지뢰찾기 키, 도움말 열기와 닫기, 언어 전환, 점수 칸 위치
- 초기 버전은 Orca 개발 폴더에 로드해 패널 화면을 캡처로 확인. 이후 레이아웃 변경은 Orca 에서 캡처하지 않았다
- 스토어 이미지(`docs/store/`)는 같은 패널 코드를 Chrome 에서 띄우고 키를 눌러 찍은 것이다. Orca 의 `plugin shot` 은 HTML 패널에서 키 입력을 지원하지 않아서 쓰지 못했다. 모니터 화면은 제외했다

## 확인하지 않은 것

- **Orca 안에서의 실제 화면**: 이후 변경(크기, 버튼, 패널 위치, 다국어)은 캡처로 보지 않았다. 가짜 DOM 은 그림과 실제 배치를 확인할 수 없다.
- **실제 키 입력**: Orca 패널에서 키를 눌러 본 적이 없다. 자동 입력 수단이 없다.
- **호스트 단축키 충돌**: Ctrl+T 는 터미널을 열었고(호스트가 먼저 받음), Ctrl+L 은 동작하지 않았다. F1, F2, Ctrl+H 는 호스트와 겹치는지 아직 확인하지 않았다.
- 여러 패널 크기에서의 레이아웃. 패널은 380px 상자 기준으로 맞췄다.
- 실제 게임 진행: 게임 오버까지 끝까지 가 본 적이 없다.

## 알려진 점

- 게임 화면을 처음 열 때는 블록이 미리 보입니다. 시작 전에는 화면만 보이고 떨어지지 않습니다.
- 모니터 수치는 가짜 난수입니다. CPU/메모리 같은 실제 값은 샌드박스에서 읽을 수 없어 넣지 않았습니다.
- 키 입력은 패널을 클릭해서 포커스를 준 뒤에 됩니다.
- 번역은 제가 작성한 것입니다. 원어민 검토를 받지 않았습니다.
- 스네이크 띠는 맨 위 칸 두 줄 정도를 가립니다. 게임 로직은 바뀌지 않습니다.
