# 소개글 준비 문서

작성일: 2026-11-18. 오늘 orca-radio 배포 과정에서 배운 내용을 정리해, orca-tetris 소개글과 목록 등록에 바로 쓸 수 있게 한 문서입니다.

## 1. 목록 등록 조건 (orca.dev 기준)

- **저장소**: 공개 GitHub 저장소, 토픽 `orca-plugin`
- **태그**: `vX.Y.Z` 형식. 새 태그가 있어야 목록이 갱신됩니다. 같은 태그 이름은 다시 쓸 수 없습니다.
- **매니페스트**: `manifestVersion` 2, `publisher` 는 생략(저장소 소유자로 자동 정해짐), `engines.orca` 는 쓰는 기능 중 가장 높은 버전 이상.
- **예약 이름 금지**: id 나 표시 이름에 `orca-` 접두사, `Orca` 로 시작하는 표시 이름, `official`·`github`·`stablyai` 같은 예약어는 쓸 수 없습니다.
  - 실제로 `orca-radio` 가 이 규칙에 걸려 `radio-for-orca` 로 바꿨습니다. **orca-tetris 도 같은 문제가 생기므로 id 와 이름을 처음부터 `tetris-for-orca` 같은 형태로 정하는 것이 좋습니다.**
- **무료만 가능**: 유료 기능, 결제 잠금, 체험판 제한은 허용되지 않습니다.
- **개인정보**: 추적이나 데이터 수집을 하면 안 됩니다.

## 2. 매니페스트에 넣을 것

| 항목 | 기준 | 비고 |
| --- | --- | --- |
| `description` | 짧은 한 문장 | 목록 카드에 나옵니다. 영문으로 쓰는 것이 좋습니다 |
| `license` | SPDX 식별자 (예: MIT) | 라이선스 파일도 함께 두기 |
| `repository` | 저장소 URL | 목록 페이지의 링크 |
| `author.name` | 제작자 이름 | 선택 |
| `icon` | 정사각형 PNG/WEBP, 128px 이상, 256KB 이하 | 선택 |
| `cover` | 16:10, 최소 800×500 (권장 1600×1000), 1024KB 이하 | `alt` 필수 |
| `screenshots` | 최대 6장, 최소 1280×800 (권장 2560×1600), 장당 1536KB 이하, 합계 8MB 이하 | `alt` 필수, `caption` 선택 |

- 모든 경로는 플러그인 폴더 기준 상대 경로입니다. `..` 는 쓸 수 없습니다.
- 알 수 없는 키가 있으면 검증이 실패합니다.

## 3. 목록 페이지에 보이는 것

- **보이는 것**: 이름, 한 줄 설명, 버전, 대표 이미지(cover), 스크린샷, 라이선스, 권한(Full access 여부), "Community · unreviewed" 표시, 설치 방법
- **보이지 않는 것**: README 본문과 README 안의 이미지. README 는 링크로만 연결됩니다.
- **README 링크**: 특정 커밋에 고정됩니다. README 를 고친 뒤에도 새 태그를 올려야 링크가 최신 커밋을 가리킵니다.
- **권한 설명**: 목록은 "파일을 읽고, 네트워크를 쓰고, 다른 프로그램을 실행할 수 있다"고 표시합니다. **README 에 왜 그런 권한이 필요한지 적어 두면** 사용자가 판단하기 쉽습니다. 인덱서 메모도 이 점을 권했습니다.

## 4. 반영 주기와 확인

- 새 태그가 목록에 반영되기까지 최대 1시간 걸립니다.
- 상태 페이지(`orca.dev/plugins/<owner>/<repo>`)에서 검사 버전과 메모를 볼 수 있습니다.
- 한 번에 여러 태그를 올려도 목록은 가장 최근 정상 태그를 기준으로 합니다. 오늘은 0.6.2 → 0.6.3 → 0.6.4 → 0.6.5 순서로 반영을 기다렸습니다.
- 메모에 "publisher 는 무시됨" 같은 경고가 나오면 매니페스트에서 그 필드를 지우고 새 태그를 올립니다.

## 5. 스크린샷과 이미지 만드는 법

- 패널 캡처는 `orca plugin shot <플러그인 키> --panel <패널 id> --out <파일>` 로 찍습니다. 패널은 사이드바 폭(약 300~500px) 기준으로 그려집니다.
- 목록 기준 크기(1280×800 이상)보다 작게 찍히므로, 캡처를 확대해 배경과 함께 합성했습니다. **확대는 선명도가 떨어지므로**, 가능하면 실제 큰 화면으로 찍거나 패널 확대 방식을 따로 준비하는 것이 좋습니다.
- 여러 디자인이나 상태를 보여 줄 때는 같은 기준 폭으로 나란히 배치하면 비교가 쉽습니다.
- 캡처 이미지는 `docs/store/` 같은 폴더에 두고, 매니페스트에서 경로로만 참조합니다.

## 6. 소개글 초안 구성 (orca-tetris)

1. 한 줄 소개 (영문, 매니페스트 `description` 에도 같은 문장을 쓴다): "Retro Tetris, Ladder, Snake and Minesweeper games in the Orca sidebar."
2. 주요 기능: 게임 4종(테트리스, 사다리, 스네이크, 지뢰찾기), 레트로 팔레트, 도움말 팝업(Ctrl+H), 7개 언어(F2로 변경), 모니터 화면(F1)
3. 조작법: 숫자 키 1~4 게임 전환, F1 모니터, F2 언어, Ctrl+H 도움말, R 다시 시작, 화살표와 Space(테트리스), WASD(스네이크, 지뢰찾기)
4. 요구 사항: Orca 1.4.246 이상. 별도 프로그램 불필요
5. 알려진 제한: 키 입력과 레이아웃을 Orca 안에서 아직 확인하지 않음, 번역 원어민 검토 전, 모니터 수치는 가짜 난수
6. 권한 설명: 샌드박스 실행(`sandboxed-ui`), 파일과 네트워크를 쓰지 않음. README 에 이 내용을 적는다
7. 라이선스(MIT)와 저장소 링크

Press F1 and a new world opens.
